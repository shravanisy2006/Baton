# EventApp demo data (synthetic)

Everything in this folder is invented for the Baton demo. No real people, organisations, emails or budgets.

The story: EventApp is a college club's event-registration app. Backend lead **Riya Sharma** is leaving and
**Karan Mehta** is taking over. **Priya Nair** reviews the handover. **Anika Joshi** is a viewer.

| File | Access label | What it demonstrates |
| --- | --- | --- |
| meeting-notes-2026-09-15.md | Team | Payments decision, a task with no owner, a risk, an open question |
| tasks-export.csv | Team | Task board export — Excel export marked **Done** |
| github-export-eventapp.md | Team | Exported GitHub PR/issue/commit — Excel export **reopened**, broken above 500 rows |
| deploy-runbook.pdf | Team | PDF parsing — recurring CI failure, a dependency |
| riya-handover-notes.docx | Leads | Word parsing — Leads-only notes |
| sponsor-notes.md | Restricted | Sponsor contact and budget — hidden from Karan and Anika |
| club-whatsapp-export.txt | Team | Chat import, one unit per message — a **newer** decision to switch payments back on (timeline check) |

`github-export-eventapp.md` is a synthetic *export* of GitHub activity, not a live GitHub connection. The live
GitHub import (Sources → Import a GitHub repository) uses the real GitHub API with any public repository.

`deploy-runbook.pdf` and `riya-handover-notes.docx` are generated by `backend/scripts/make_seed_files.py`.
`llm_cache.json` (when present) holds real Gemini responses saved by `backend/scripts/export_demo_cache.py`.
